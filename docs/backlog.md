# Candidate Backlog

Candidates are possibilities, not promises. Use `Target Release` only after an item is planned; a blank target means no commitment.

Statuses: Candidate → Planned → Specified → In Progress → Released (or → Rejected; → Parked while a missing prerequisite blocks planning). `Specified` from the moment a story spec naming the row exists; `In Progress` once its build starts.
